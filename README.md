## Featured work

### [RPT](https://apps.apple.com/us/app/rpt-reverse-pyramid-training/id6745407020) — Reverse Pyramid Training
A strength-training log built around one method: log the heaviest set first, and the app calculates every back-off set. Free core loop, one-time Pro unlock, all data on device. [Source](https://github.com/MichaelMade/RPT)

### [RoutineCut](https://apps.apple.com/us/app/routinecut-floor-music-cut/id6794163070) — Floor-music editing for gymnastics
An iPhone app that cuts a song you already own to a routine time limit, with phrase-aware cut suggestions, a waveform editor, and on-device processing. No account and no uploads.

### [threee](https://apps.apple.com/us/app/threee-daily-top-3/id6836048593) — Daily top 3 with friends
A private social app: one shared question a day, three short answers, and a friends-only reveal. 18+, invite-only, no public feed. [threee.app](https://threee.app)

### [Multi-agent customer support](https://github.com/MichaelMade/capstone-multi-agent-customer-support)
A LangGraph and LangChain customer-support system over a demo database: catalog answers stay grounded in tools, invoice access is gated by verified customer identity, and a human can approve sensitive steps before they run. Python, Gradio, and an automated test suite that does not need live model calls.

### [PTK Tablet Driver](https://github.com/MichaelMade/ptk-tablet-driver)
A native Apple Silicon macOS driver that brings the unsupported Wacom Intuos4 Large (PTK-840) back to life — pressure, eraser, ExpressKeys, and the Touch Ring — shipped with a signed, notarized installer.

### [TaskLift](https://tasklift.tech)
Appointment-reminder software for Charlotte small businesses. Connect Google Calendar and queue reminders from the appointments already on the books.
